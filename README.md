# 수학 오답노트 - AI 수학 어시스턴트
     2	
     3	두 아들을 위한 AI 기반 수학 오답 관리 시스템입니다. OpenAI Vision API를 활용하여 문제 사진을 자동으로 분석하고, 체계적으로 오답을 관리할 수 있습니다.
     4	
     5	## 🌟 주요 기능
     6	
     7	### ✅ 현재 구현된 기능
     8	
     9	#### 1. **AI 수학 어시스턴트** 🤖
    10	- **문제 사진 자동 분석**: OpenAI GPT-4o Vision을 사용하여 수학 문제 이미지를 분석
    11	- **자동 정보 추출**: 문제 내용, 과목/단원, 난이도, 정답, 틀린 이유 등을 자동으로 추출
    12	- **대화형 인터페이스**: AI 챗봇과 대화하며 학습 조언 받기
    13	- **자동 저장**: 분석된 내용을 데이터베이스에 자동 저장
    14	
    15	#### 2. **오답 관리**
    16	- **다양한 입력 방식**:
    17	  - 텍스트로 직접 입력
    18	  - 이미지 파일 업로드
    19	  - 이미지 URL 입력
    20	  - AI를 통한 자동 입력
    21	- **상세한 정보 기록**:
    22	  - 학생 정보 (첫째/둘째)
    23	  - 문제 풀이 날짜
    24	  - 과목/단원
    25	  - 문제 유형
    26	  - 난이도 (상/중/하)
    27	  - 출처 (학원/자습/시험 등)
    28	  - 내가 쓴 답 / 정답
    29	  - 틀린 이유
    30	  - 태그 (실수 유형, 개념 등)
    31	
    32	#### 3. **오답 목록 게시판**
    33	- **필터링 기능**:
    34	  - 학생별 필터
    35	  - 난이도별 필터
    36	  - 마스터 상태별 필터
    37	  - 검색 기능
    38	  - 정렬 (최근 등록순, 풀이 날짜순, 난이도순, 복습 많은순)
    39	- **통계 요약**: 전체 오답수, 이번 달 오답, 복습 필요, 완전 이해
    40	- **카드 형식 표시**: 깔끔한 카드 UI로 문제 정보 표시
    41	
    42	#### 4. **월별 분석 리포트**
    43	- **기간별 분석**:
    44	  - 이번 달 / 지난 달
    45	  - 최근 3개월 / 6개월
    46	  - 올해 / 전체
    47	  - 사용자 정의 기간
    48	- **통계 대시보드**:
    49	  - 총 오답 수
    50	  - 평균 난이도
    51	  - 복습 필요 개수
    52	  - 마스터율
    53	- **차트 분석** (Chart.js 준비됨):
    54	  - 월별 오답 추이
    55	  - 난이도별 분포
    56	  - 과목/단원별 오답
    57	  - 복습 현황
    58	
    59	#### 5. **복습 인터페이스**
    60	- **다양한 복습 모드**:
    61	  - 우선순위 복습 (복습이 필요한 문제 우선)
    62	  - 랜덤 복습
    63	  - 어려운 문제만 복습
    64	  - 맞춤 필터 복습
    65	- **복습 세션**:
    66	  - 진행 상황 표시
    67	  - 문제 표시
    68	  - 답변 입력
    69	  - 정답 확인
    70	  - 결과 기록 (정답/부분정답/오답)
    71	  - 복습 노트 작성
    72	- **복습 결과 요약**: 정답/부분정답/오답 통계
    73	
    74	#### 6. **설정 페이지**
    75	- **OpenAI API 키 관리**:
    76	  - API 키 입력 및 저장 (브라우저 로컬 스토리지)
    77	  - 연결 테스트
    78	  - API 키 표시/숨김 토글
    79	- **AI 설정**:
    80	  - 모델 선택 (GPT-4o, GPT-4o Mini, GPT-4 Turbo)
    81	  - 자동 저장 옵션
    82	  - 응답 언어 설정 (한국어/English)
    83	- **데이터 관리**:
    84	  - 데이터 백업 (JSON 내보내기)
    85	  - 데이터 복원 (JSON 가져오기)
    86	  - 전체 데이터 삭제
    87	
    88	#### 7. **대시보드**
    89	- **학생별 통계**: 각 학생의 총 오답수와 이번 달 오답수
    90	- **빠른 실행**: 주요 기능 바로가기
    91	- **최근 등록된 오답**: 최신 5개 오답 표시

   116	
   117	### Students (학생)
   118	- `id`: 학생 ID
   119	- `name`: 학생 이름
   120	- `grade`: 학년
   121	- `created_at`: 등록일
   122	
   123	### Wrong Problems (오답 문제)
   124	- `id`: 문제 ID
   125	- `student_id`: 학생 ID
   126	- `student_name`: 학생 이름
   127	- `subject`: 과목/단원
   128	- `problem_type`: 문제 유형
   129	- `difficulty`: 난이도 (상/중/하)
   130	- `content`: 문제 내용 (텍스트)
   131	- `image_url`: 문제 이미지 URL
   132	- `mistake_reason`: 틀린 이유
   133	- `correct_answer`: 정답
   134	- `my_answer`: 내가 쓴 답
   135	- `source`: 출처
   136	- `solved_date`: 문제 풀이 날짜
   137	- `registered_date`: 등록 날짜
   138	- `review_count`: 복습 횟수
   139	- `last_review_date`: 마지막 복습 날짜
   140	- `mastered`: 완전히 이해했는지 여부
   141	- `tags`: 태그 배열
   142	
   143	### Review Records (복습 기록)
   144	- `id`: 복습 기록 ID
   145	- `problem_id`: 문제 ID
   146	- `student_id`: 학생 ID
   147	- `review_date`: 복습 날짜
   148	- `result`: 복습 결과 (정답/오답/부분정답)
   149	- `notes`: 복습 노트

   151	## 🚀 시작하기
   152	
   153	### 1. OpenAI API 키 발급
   154	
   155	1. [OpenAI 계정 생성](https://platform.openai.com/signup)
   156	2. [API Keys 페이지](https://platform.openai.com/api-keys)에서 새 API 키 생성
   157	3. 생성된 API 키를 복사
   158	
   159	### 2. API 키 설정
   160	
   161	1. 웹사이트 접속 후 **설정** 페이지로 이동
   162	2. "OpenAI API 키 설정" 섹션에서 API 키 입력
   163	3. **저장** 버튼 클릭
   164	4. **연결 테스트** 버튼으로 API 키 확인
   165	
   166	### 3. AI 어시스턴트 사용하기
   167	
   168	#### 방법 1: 메인 페이지에서 바로 사용
   169	1. 메인 페이지의 "AI 수학 어시스턴트" 섹션에서 **시작하기** 클릭
   170	2. 학생 선택
   171	3. 문제 사진 업로드
   172	4. **AI로 분석하기** 클릭
   173	5. AI가 자동으로 문제를 분석하고 저장
   174	
   175	#### 방법 2: 수동으로 등록 후 보완
   176	1. **오답 등록** 페이지에서 기본 정보 입력
   177	2. 필요시 AI 어시스턴트로 추가 분석

   289	## 🙋 FAQ
   290	
   291	**Q: API 키가 유출되면 어떻게 하나요?**
   292	A: 즉시 OpenAI 대시보드에서 해당 키를 삭제하고 새 키를 발급받으세요.
   293	
   294	**Q: 데이터는 어디에 저장되나요?**
   295	A: 브라우저의 IndexedDB와 제공된 RESTful API에 저장됩니다. 정기적으로 백업하세요.
   296	
   297	**Q: 오프라인에서도 사용할 수 있나요?**
   298	A: 등록된 데이터 조회는 가능하지만, AI 기능은 인터넷 연결이 필요합니다.
   299	
   300	**Q: 이미지를 Base64로 저장하면 용량이 크지 않나요?**
   301	A: 맞습니다. 가능하면 이미지 URL을 사용하거나 외부 이미지 호스팅을 추천합니다.
   302	
   303	**Q: 형제가 더 있어도 추가할 수 있나요?**
   304	A: 네, 설정에서 학생 데이터를 추가하면 됩니다 (향후 UI 개선 예정).
