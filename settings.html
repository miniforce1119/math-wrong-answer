OpenAI API 키 설정

API 키가 필요한 이유

AI 어시스턴트 기능을 사용하려면 OpenAI API 키가 필요합니다. API 키는 브라우저에만 안전하게 저장되며, 서버로 전송되지 않습니다.

API 키 상태

설정되지 않음

API 키는 브라우저의 로컬 스토리지에만 저장됩니다.

API 키 발급 방법

  1. OpenAI 계정 생성
  2. API Keys 페이지 방문
  3. "Create new secret key" 버튼 클릭
  4. 생성된 API 키를 복사하여 위 입력창에 붙여넣기
  5. "저장" 버튼 클릭

예상 비용: 이미지 분석 1회당 약 $0.01~0.05 정도 소요됩니다. 한 달에 100개 문제를 분석해도 $5 미만의 비용이 발생합니다.
